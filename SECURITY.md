# Security Policy

## Supported Versions

PromptShield is currently in early development. Security fixes are applied to the latest version on the default branch.

## Reporting a Vulnerability

Please do not open a public issue for sensitive security reports.

If you find a vulnerability, report it privately to the project maintainer. Include:

- A short description of the issue
- Steps to reproduce
- Affected files or commands
- Any relevant logs with secrets redacted

## Secret Handling

Never include real API keys, tokens, passwords, private keys, or `.env` contents in issues, pull requests, screenshots, or logs.

PromptShield is designed to scan local files. Review generated reports before sharing them because reports may contain snippets from the scanned project.
